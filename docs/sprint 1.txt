## API Response Standard

Created a generic `ApiResponse<T>` class to ensure all REST APIs return a consistent response structure.

### Fields
- success
- message
- data
- timestamp

### Why?
- Consistent API contract
- Easier frontend integration
- Simpler testing
- Standardized error handling

## Global Exception Handling

Implemented centralized exception handling using `@RestControllerAdvice`.

### Benefits

- No repetitive try/catch blocks
- Standard error response format
- Easier maintenance
- Better security (no stack traces exposed to clients)
